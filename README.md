# 工时打卡

一个可在手机上运行的轻量打卡小工具：纯前端、数据保存在本机浏览器，无需后端和账号。

## 功能

- 每天点「上班打卡」「下班打卡」记录上下班时间
- 可设置：每天正常工时（默认 8 小时）、午休时长（默认 30 分钟）、每月休息天数（默认 4 天）
- 当天时长 = 下班时间 - 上班时间 - 午休时长
- 三种记录类型：
  - **上班**：正常出勤，超出正常工时的部分算加班
  - **休息日**：正常工时为 0；不上班不扣任何时长，上班则全部算加班（哪天休息可自选）
  - **调休**：当天记为 −正常工时（例如 -8 小时），用于抵扣已累积的加班时长
- 自动统计：上班天数、休息天数、调休天数、综合上班工时、累计加班工时
- 日历视图：按月查看，用颜色区分 正常 / 休息 / 调休 / 加班，并显示本月休息天数进度
- 支持补录、编辑、删除记录，以及导出 / 导入 JSON 备份

## 计算示例

按正常工时 8 小时、午休 0.5 小时：

- 7:00 上班、17:00 下班 → 当天时长 9.5 小时 → 加班 +1.5 小时
- 第二天调休 → 当天时长 -8 小时 → 累计加班 1.5 − 8 = -6.5 小时
- 某天设为休息日（未上班）→ 时长 0，加班余额不变
- 休息日上班 9:00–18:00、午休 1 小时 → 时长 8 小时 → 全部算加班 +8 小时

## 在手机上使用

任选一种方式：

1. **本地静态服务器（推荐，手机与电脑同一 Wi-Fi）**

   ```powershell
   cd "E:\codex\work hour"
   python -m http.server 8000
   ```

   手机浏览器访问 `http://电脑局域网IP:8000`，然后「添加到主屏幕」。

2. **GitHub Pages**：直接访问 https://whale47-x.github.io/work-hour/ ，在手机浏览器里「添加到主屏幕 / 安装应用」，即可像 App 一样使用并离线打开。

3. **直接把整个文件夹拷到手机**，用支持打开本地 HTML 的工具查看（此方式无法启用离线缓存和安装）。

## 更新发布

改完代码后，在项目目录执行一条命令即可提交并上线：

```powershell
.\deploy.ps1 "本次改动说明"
```

## 数据说明

- 数据保存在手机浏览器的 `localStorage`，卸载应用或清除浏览器数据会丢失，建议定期「导出」备份。
- 「导入」会覆盖当前所有记录和设置。

## 文件

- `index.html` — 主程序（样式和逻辑均内联，便于部署）
- `manifest.json` — PWA 清单
